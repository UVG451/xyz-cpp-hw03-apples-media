# ДЗ 3. Текстуры и звук в «Яблоках»

Игрок меняет ориентацию при движении. У яблок и камней есть текстуры, подбор и столкновения сопровождаются звуком. Состояние игры и функции находятся в пространстве имён `ApplesGame`.

## Сборка и запуск

Откройте `Game.sln` в Visual Studio 2022 с компонентом «Разработка классических приложений на C++». Выберите Release x64, соберите решение и нажмите Ctrl+F5. Библиотеки SFML и игровые ресурсы доступны в репозитории.

После сборки папка `ApplesGame/x64/Release` содержит исполняемый файл, DLL и ресурсы. Запускайте `ApplesGame.exe` с рабочим каталогом этой папки.
